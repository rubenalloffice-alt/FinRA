Excel Data Management

Export all your entries to an Excel file, or download an empty template for importing many entries at once. Needs internet.

Import from Excel

Fill the template, then choose the file. You see a preview check first and nothing is saved until you press Import. If any row has a problem, nothing is imported: fix the file and choose it again. Choosing the same file twice never makes duplicates.

Automated Backups

A copy of the whole database is made automatically every month. You can also make an instant backup now.
